# Контекст проекта

Статическое портфолио Жени Калашникова. Публикуется содержимое `dist`. Сборки, пакетного менеджера, линтера и тестов в репозитории нет. `AGENTS.md` нет.

## Запуск

Локально: открыть `dist/index.html` или поднять статический сервер из корня репозитория и открыть `/dist/index.html`.

Страницы: `dist/index.html`, `dist/privacy.html`, `dist/terms.html`, `dist/consent.html`.

Стек: HTML, CSS (`dist/assets/portfolio.css`, `dist/assets/legal.css`), ванильный JS (`dist/assets/portfolio.js`, `dist/assets/legal.js`). Шрифты Manrope и Unbounded с Google Fonts. React, Next.js и бэкенда нет. Заявка не сохраняется на сайте: форма открывает `https://t.me/+79122204032` или `https://max.ru/:share` с закодированным текстом. Сообщение уходит только после действия пользователя в мессенджере.

## Аудит 18 октября 2026

Проверено по навыкам frontend-design, web-design-guidelines, responsive-visual-qa, security-best-practices (vanilla JS) и Playwright. React Best Practices и backend-quality не применялись: стека нет. Context7 не нужен: версионируемых библиотек нет.

Playwright CLI (`@playwright/cli`, Chromium) против локального сервера. Ширины 360, 390, 600, 768, 900, 980, 981, 1024, 1199, 1200, 1440 CSS px, высота в основном 900. Сценарии: меню, якоря, альбом, карточка услуги, форма заявки без реальной отправки (подмена `window.open`), юридические страницы, `prefers-reduced-motion`. Консоль без ошибок, ответов 4xx нет. Это не проверка Safari и не физического iPhone.

Контраст основных текстов на бумаге, лайме и тёмном фоне от 4.55:1 и выше.

### Исправлено

- Пункт меню с якорем не прокручивал страницу: после закрытия возвращался прежний `scrollY`. Теперь после закрытия страница доскролливается до раздела и фокус встаёт на него.
- Пока меню открыто, фон (`main`, подвал, шапка, ссылка «К содержанию») получает `inert`. Escape возвращает фокус на кнопку «Меню».
- На ширине до 640 px панель меню на всю ширину: узкая шторка обрезала логотип в шапке. На 768 px шторка 340 px и логотип не режет.
- «Заполнить заявку» закрывает карточку услуги и оставляет одно окно заявки. Один Escape закрывает его и снимает блокировку прокрутки.
- В меню юридических страниц добавлены WhatsApp и Telegram, как на главной.
- Крупнее цели касания: точки отзывов 44 px, чекбокс согласия 24 px, стрелки альбома на узком экране 44 px, у коротких ссылок контактов расширена зона нажатия.
- У кнопок альбома и точек отзывов убраны роли вкладок без клавиатурного паттерна вкладок. У полей формы, кроме имени, стоит `autocomplete="off"`.

Пользовательские незакоммиченные правки (фавикон, полноэкранный мобильный герой, альбомы, тексты) не откатывались.

### Не закрыто

- У ролика нет субтитров и расшифровки: текста реплик в проекте нет.
- Google Fonts подключаются без SRI. CSS Google зависит от браузера, хеш на нём не держится. Отдельной подтверждённой XSS нет: пользовательский текст не вставляется как HTML, адреса мессенджеров фиксированы.
- Заголовков CSP в репозитории нет. Их должен ставить хостинг. В мета-тег CSP не добавлялся: сломает шрифты и инлайновые стили.
- Файл обложки ужина называется `event-dinner-cover..png` (две точки). Имя совпадает с CSS и README, не переименовывалось.
