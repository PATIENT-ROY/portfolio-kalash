# Женя Калашников — портфолио

Статический сайт. Для публикации загрузите содержимое `dist` на хостинг. Локально откройте `dist/index.html`.

Видео в `dist/assets/host-reel.mp4` обрезано из записи экрана Instagram: убраны статус-бар, шапка и панель лайков. Исходный ролик на сайте больше не лежит.

В каждом альбоме три кадра. Обложки — Женя: `event-wedding/event-wedding-cover.png`, `event-dinner/event-dinner-cover..png`, `event-corporate/event-corporate-cover.png`. Вторые и третьи кадры лежат рядом: `wedding-1.png`, `wedding-2.png`, `dinner-1.png`, `dinner-2.png`, `corporate-1.png`, `corporate-2.png`. Ролик `host-reel.mp4` вертикальный и с субтитрами, кадры из него в альбом не резал.
